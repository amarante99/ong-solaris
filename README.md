# ONG Solaris — projeto Front-End

Projeto acadêmico fictício de uma ONG, desenvolvido com HTML5 e CSS3.

## Estrutura
- `index.html` — página inicial
- `projetos.html` — projetos, doações e voluntariado
- `cadastro.html` — cadastro de apoiadores e validações nativas
- `contato.html` — informações e formulário de contato
- `assets/css/style.css` — estilos
- `assets/*.svg` — logo e imagens vetoriais

## Validações
CPF, telefone e CEP usam `pattern`; campos obrigatórios usam `required`; e-mail usa `type="email"`; data usa `type="date"`; telefone usa `type="tel"`.

## Publicação
O projeto pode ser publicado gratuitamente pelo GitHub Pages. Depois de criar um repositório, envie todos os arquivos mantendo a estrutura de pastas e ative Pages em Settings > Pages.
